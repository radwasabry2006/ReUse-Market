# ReUse Market

## 📌 Project Overview
ReUse Market is a web platform that allows users to sell their used products or offer them for free as donations. Users can browse product categories, search and filter products by category and price, view product details and condition, and contact product owners. The platform encourages reuse, reduces waste, and helps people find affordable products.

## 🎯 Project Objectives
- Make buying and donating used products easier.
- Encourage reuse and reduce waste.
- Help users find affordable products.
- Provide a simple and user-friendly experience.
- Allow users to manage product listings and save favorite products.

## 📦 Project Scope
- User Registration and Login
- Home Page and Product Categories
- Search and Filter by Category and Price
- Product Details (Image, Description, Price, and Condition)
- Add New Product Listings
- Edit and Delete Product Listings
- Favorites Page
- Contact Product Owner
- Responsive and User-Friendly Interface

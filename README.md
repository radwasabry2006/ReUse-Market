# ReUse Market ♻️

A web platform for selling and donating used products, encouraging reuse and reducing waste.

## 📌 Project Overview

ReUse Market is a web platform that allows users to sell their used products or offer them for free as donations.

Users can browse different product categories, search and filter products by category and price, view detailed product information, and contact product owners.

Our goal is to encourage reuse, reduce waste, and help people find affordable products through a simple and user-friendly experience.

## 🎯 Project Objectives

- Make buying and donating used products easier.
- Encourage reuse and reduce waste.
- Help users find affordable products.
- Provide a simple and user-friendly experience.
- Allow users to manage product listings and save favorites.

## ✨ Main Features

- User Registration and Login.
- Home Page and Product Categories.
- Search and Filter by Category and Price.
- Product Details (Images, Description, Price, and Condition).
- Add, Edit, and Delete Product Listings.
- Favorites Page.
- Contact Product Owner.
- Responsive User Interface.

## 🚀 Getting Started

To run the project locally:

1. Clone the repository:

   `git clone https://github.com/radwasabry2006/ReUse-Market.git`

2. Navigate to the project folder:

   `cd ReUse-Market`

3. Install dependencies:

   `npm install`

4. Start the development server:

   `npm run dev`
